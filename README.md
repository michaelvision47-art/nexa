# NEXABLOOM

Software consulting website for **NEXABLOOM** — public marketing pages, careers, candidate flow, and client / employee / admin portals.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo login

Use any password with:

| Email | Destination |
| --- | --- |
| client@nexa-blooms.com | Client portal |
| employee@nexa-blooms.com | Employee portal |
| admin@nexa-blooms.com | Admin portal |
| candidate@nexa-blooms.com | Candidate portal |

## Stack

Next.js App Router, TypeScript, Tailwind CSS, Lucide icons.
